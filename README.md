# Pokédex Scanner Pokémon

API-first prototype for matching OCR observations to Pokémon catalog records.

## Status

Version **0.1.0** is an experimental public starter project. It separates image acquisition, text recognition and catalog matching so each stage can be replaced independently.

## Planned components

- FastAPI service
- Unicode-aware text normalization
- Ranked name, alias and Pokédex-number matching
- Demonstration catalog and synthetic requests
- Automated tests and CI
- Privacy-conscious image processing

This is an unofficial educational fan project and is not affiliated with Nintendo, Creatures Inc. or GAME FREAK.
