# Roadmap

## 0.2 — Image input

- Add a replaceable OCR adapter
- Enforce image size and media-type limits
- Add rotated and low-contrast fixtures
- Avoid retaining camera frames by default

## 0.3 — Ranking

- Combine name, number and category evidence
- Calibrate confidence against a labeled dataset
- Explain contributing observations
- Return an explicit unknown result

## 0.4 — Card mode

- Detect common card regions
- Extract set and collector numbers
- Keep card metadata separate from species data

A mobile client, offline catalog packages and multilingual aliases are possible later directions.
